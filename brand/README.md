# brand

Drop what already exists here. The skills treat it as starting material, not
suggestions.

- **Logo** in SVG, plus any lockups and a favicon source
- **Colors** as hex or oklch, and which is primary vs accent
- **Type** the licensed or chosen faces, with weights
- **Photography** real shots, or the direction if there are none yet
- **Voice** how the product talks, and what it never says

Anything absent gets inferred from the brief and stated out loud.

`design-taste-frontend` §0.A reads this as signal 5. On a redesign it is required
input, and §11 says an existing brand color stays recognisable rather than being
restyled away.

Empty folder means greenfield. Delete this file once real assets land.
